Agent Orchestrator follows a weekly release train with two channels: **stable** (the default, tested and recommended for production use) and **nightly** (early access to in-flight changes, shown with a badge in the sidebar). You can switch channels in Settings under Updates, or with the Developer Mode toggle to access Feature Releases — installable builds from any open pull request.

Run `ao --version` to check your installed version. GitHub Releases and Homebrew are the supported install paths.
