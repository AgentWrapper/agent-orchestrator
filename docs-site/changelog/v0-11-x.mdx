The v0.11 series landed in late July 2026 and represents the most substantial release cycle in AO's history — 271 commits and 270 merged PRs from 49 authors between v0.10.0 and v0.11.0 alone. The theme is foundation: the core architecture finally holds weight, and new features (mobile, browser, keyboard navigation) are built on top of a stable base rather than around it.

  <Accordion title="v0.11.2 — July 30, 2026">

    A reliability and polish release on top of v0.11.1, plus a major feature: every AO worker session now gets its own live, session-owned browser.

    **Features**
    - Every AO worker gets a live, session-owned browser (#3066) — agents can render and interact with a browser tied to their specific session
    - Durable idle-orchestrator re-engagement: idle orchestrators are reliably woken up through a persistent outbox mechanism (#3274)
    - macOS release hardening: updated e2e tests, verify script, DMG maker, and a single-publisher rule to prevent accidental duplicate releases (#3294)
    - Warn when creating a workspace inside an ancestor Git repository (#3271)

    **Bug fixes**
    - Fixed split lane board scrolling not being shared across panes (#3187)
    - Fixed macOS zip releases including an unnecessary blockmap sidecar (#3151)
    - Fixed Crush agent not forwarding role-specific model config on launch (#3155)
    - Fixed Agy agent not honoring `cfg.Config.Model` via the `--model` flag on launch and restore (#3167)
    - Fixed foreign PR auto-attribution — PRs from other users are no longer incorrectly claimed by AO sessions (#3262)
    - Fixed merged board lane sorting: newest entries now appear first (#3308)
    - Improved project removal and session termination UI (#3324)
    - Fixed tmux runtime wasting the reap grace period when `pkill` cannot match a session (#3328)
    - Fixed dev mode using the same Electron profile as the installed app (#3330)
    - Replaced terminal tab strip session picker with a cleaner new-terminal button (#3275)
    - Fixed telemetry: split current events from the legacy PostHog firehose (#3314)
    - Fixed OpenCode and Kilo Code accepting free models without detected auth (#3358)
    - Various landing site fixes: sitemap URLs, social profile links, branding consistency, and hero spelling (#3276–3342)

    **New contributor:** @vanshx999

  <Accordion title="v0.11.0 'The Floor' — July 26, 2026">

    271 commits. 270 merged PRs. 49 authors. v0.10.0 was the promise — v0.11.0 is where the foundation actually holds weight.

    > Covers everything since v0.10.0. If you are on v0.10.3, you already have part of this.

    ### Your phone is a real control surface

    The mobile companion app graduated from a port to a shipping surface. Pair your phone to the AO daemon over LAN using a password via **Connect Mobile**, co-view terminals with pinch-to-zoom and pan, and receive **push notifications on iOS and Android** when a session needs your attention. Settings walks you through LAN or Tailscale pairing and links directly to the app. (#2522, #2533, #2569, #2654, #2851, #2881, #2918, #2933)

    ### Agents can drive a browser

    Agents can now render Markdown and drive an embedded browser preview. Annotate directly inside the preview to point an agent at a specific UI element, and localhost links clicked in a terminal open there instead of bouncing you out of the app. (#2455, #2548, #2610, #3085)

    ### Feature Releases — install any open PR

    Every pull request can now produce its own installable prerelease build, so testing an in-flight change means installing a real app rather than doing a checkout. Gated behind a new **Developer Mode** toggle so the channel picker stays out of the way for everyone else. (#2459, #3039)

    ### GitHub issue intake

    Projects can automatically start a worker session per assigned GitHub issue — with polling, deduplication, pagination, and per-project backoff. Configure under **Tracker Intake** in project settings or the create-project flow. (#2325)

    ### Workspace files and a diff viewer that parses

    A new inspector panel lets you browse a session's workspace files. The Changes view now renders a properly parsed diff with gutters, hunk headers, +/- markers, and an adds/dels summary, instead of raw `git diff` text with broken line numbers. (#2772, #3013)

    ### Standalone shell terminals

    Open a plain terminal not bound to any agent session — scoped per session, renameable, with a right-click context menu, drag-a-file-to-insert-path, and sane tab overflow. (#2828, #2861, #2948, #2644, #3019, #3077)

    ### Keyboard-first navigation

    Experimental Cmd/Ctrl+K command palette, sidebar search shortcut, spawn shortcut, settings and session-navigation shortcuts, terminal-focus shortcuts, an in-app shortcuts reference, and Enter-to-send / Shift+Enter-for-newline in the New Task brief to match Claude and Codex. (#2687, #2695, #2795, #2954, #2955)

    ### Also new in this release

    - Paste, drag-drop, or attach **images** directly into a task brief (#2722, #2907)
    - **Restart-to-update** row with per-channel escalation, a revamped Updates screen, and background update checks that actually work (#2381, #2709, #2939)
    - **CLI**: `ao agent ls` with install and auth status, `ao spawn` now resolves project context instead of demanding `--project`, `--kind worker|orchestrator` flag, `ao review stop|restart`, `ao pr` (#2371, #2416, #2669, #2673, #3043)
    - **Settings and first run** rebuilt — redesigned settings with the PR board folded into the per-session inspector, onboarding replacing four empty kanban columns, and a first-run scratch project so there's somewhere to try AO immediately (#2432, #2797, #2952, #2348)
    - Renderer moved to a **token-based design system** (~1.4k lines of legacy CSS removed), followed by a unified framed desktop shell across macOS, Windows, and Linux (#2535, #2937, #2997)

    ### Reliability

    **Sessions survive restarts.** Sessions now resume the agent's own native transcript rather than restarting cold, with a toast when AO has to fall back to replaying the saved prompt. Per-harness restore landed for OpenCode, Copilot, Agy, Kimi, Grok, Qwen, Goose, and Vibe, backed by a test proving sessions survive daemon restart _and_ upgrade. (#2350, #2744, #2765, #2790, #2796, #2856–#2858)

    **Model config actually reaches the agent.** The model you picked in settings was silently dropped for most agents. Fixed across Codex, Cline, Goose, Auggie, Pi, Vibe, Autohand, Kimi, Kilocode, Qwen, and Copilot. Kiro now advertises its model options. (#2869, #2932, #2953, #2956, #2961, #2969–#2993, #3044)

    **Lifecycle and coordination.** Killed sessions stay dead. Worker-idle completions reach a busy orchestrator through a durable outbox instead of being dropped. Orchestrator replacement goes through a safe canonical branch handoff with stale worktree recovery. AO no longer nudges a session genuinely paused on a permission dialog. (#2319, #2320, #2357, #2431, #2530, #2600, #2794, #2798, #2799, #2836, #3072)

    **Daemon failures explain themselves.** Start failures surface the real error with recovery instructions and copyable output as a floating toast. `ao spawn --issue` without a GitHub token no longer panics the daemon. (#2690, #2871, #2972, #3017)

    **tmux and terminal.** Fail fast with a clear message when tmux is missing, correct `TERM` on attach, forced UTF-8 client mode so non-ASCII stops garbling, pane descendants reaped on destroy (no zombie processes), no more double-firing Ctrl+Arrow / Ctrl+Backspace / Ctrl+V, wheel scroll in Codex and OpenCode transcripts, startup state instead of a blank pane while launching. (#2259, #2312, #2466, #2499, #2512, #2586, #2602, #2650)

    **Upgrade safety.** Two duplicate migration-version collisions resolved; out-of-order migrations are now applied instead of silently skipped. (#2294, #3035, #3092)

    **Windows.** NSIS installer shortcut points at the real binary, `.ico` taskbar icon, ConPTY `ProgramFiles(x86)` fix, Codex preferring the npm binary over the WindowsApps stub, npm-installed agent binaries found when launched from the GUI, native notifications, a custom titlebar, and background auth checks routed through `aoprocess` so console windows stop flashing. (#2404, #2481, #2566, #2583, #2666, #2691, #2838, #3006)

    **PR review.** Reviewer enforced read-only via a tool allowlist, binary preflighted with unavailable options disabled before a run is created, pane respawned when the harness changes, cross-fork PR detection across all remotes, forced re-fetch past max age so the list stops going stale, and the previous-head verdict shown as context while a new review runs. (#2193, #2194, #2368, #2506, #2678, #2750, #2767, #2800, #3008, #3009, #3049)

    ### Under the hood

    The agent adapter layer was consolidated, cutting ~3,100 lines of duplication into shared `agentbase` and `activitystate` packages. The release pipeline gained channel awareness, retried macOS sign/notary flakes, a guard on the `latest` desktop release, an advisory e2e gate against real installed builds before a stable cut, and a dispatchable unsigned build-artifacts workflow that emits the Linux `.deb`. TypeScript typechecking added to frontend CI. Telemetry capped in volume, switched to anonymous IDs, and no longer leaks raw CLI args into error events.

    Docs and the landing site now deploy to [aoagents.dev](https://aoagents.dev) via GitHub Pages, with a privacy policy, a PR-wise changelog, platform-detecting download links, and a contributing guide.

    ### Upgrading

    GitHub Releases and Homebrew are the supported install paths; the npm package is frozen. Existing installs should update in place — the migration ordering fixes in this release specifically target the "it broke after updating" class of failure.
